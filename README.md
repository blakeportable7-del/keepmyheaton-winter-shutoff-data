# Winter Utility Shutoff Protections by U.S. State, 2026-27 (Keep My Heat On)

This dataset covers winter protections against residential gas and electric shutoffs for nonpayment in 11 U.S. states for the 2026-27 heating season: the dates, who is covered and the official rule, with heating assistance (LIHEAP) timing.

Published by Keep My Heat On (https://keepmyheaton.org/), an independent public resource run by Willow Creek Group LLC, St. Clairsville, Ohio. It is not a government agency.

## How it was made

Each row was checked individually against official sources only: state Medicaid, aging, utility commission and water utility pages, statutes, administrative code and federal agency pages. Every fact carries its official source and the date it was checked. Where an official page does not state something, the dataset says so (for example "Not confirmed" or "Unknown") rather than guessing.

Rules change. Check the official source in each row before relying on a value.

## Files

### winter-shutoff-rules-2026-27.csv

One row per state: the winter shutoff protection and its dates, who is covered, heating assistance (LIHEAP) timing, the rule source and the assistance source with links, and the date checked.

11 rows. Columns:

- `State`
- `Starts`
- `Ends`
- `Winter shutoff protection`
- `Who is covered`
- `Temperature rule`
- `Heating help (LIHEAP)`
- `Notes`
- `Rule source`
- `Rule source URL`
- `Heating help source`
- `Heating help URL`
- `Last checked`
